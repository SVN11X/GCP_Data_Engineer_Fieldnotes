# LICENSES

License texts of the third-party assets this repository ships, one file per asset or family, named after the SPDX identifier (for example `OFL-1.1.txt`). The text of the license for the code is in `LICENSE` at the root.

Today this folder holds no asset licenses because the site bundles no third-party fonts, icons, illustrations, scripts or media. The 349 imported questions and the 25 source images were supplied by the owner and are described in `docs/goals.md`, not relicensed here.

Every item that adds a third-party asset (fonts, icons, illustrations, video) adds its license text here and a row to `docs/credits.md` in the same pull request.
